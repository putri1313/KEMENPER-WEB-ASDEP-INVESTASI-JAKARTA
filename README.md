# Invest Indonesia Tourism (49)

Build a complete, modern, premium, responsive Indonesia Tourism Investment Portal website.

The website is intended to present information about Indonesia's tourism investment landscape, particularly:

3 Regenerative Tourism Destinations

Bali

Greater Jakarta

Kepulauan Riau

10 Priority Tourism Destinations

Danau Toba

Lombok–Gili Tramena

Borobudur–Yogyakarta–Prambanan

Labuan Bajo

Manado–Likupang

Bromo–Tengger–Semeru

Raja Ampat

Bangka Belitung

Wakatobi

Morotai

The website should feel like an official government tourism investment promotion portal: professional, trustworthy, elegant, modern, informative, and visually strong.

This is NOT a travel booking website.

Do not create hotel booking functionality, flight booking, tourism package booking, or e-commerce functionality.

The main purpose is:

DESTINATION INFORMATION → TOURISM POTENTIAL → INVESTMENT POTENTIAL → INVESTMENT OPPORTUNITIES → REGULATIONS → PUBLICATIONS → INVESTMENT INQUIRY

Use the uploaded mockup as the main visual reference for the overall information architecture and visual direction.

The mockup contains a navigation structure, tourism investment hero section, "Why You Should Invest" section, featured projects, project classification, thematic opportunities, investor testimonials, publications, newsletter, and contact section. Maintain this overall storytelling approach while improving it into a more complete destination-focused investment portal.
